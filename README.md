# Connect 4 Negamax Solver

## Project layout

- `solver/` contains the array and bitboard game implementations and Negamax solvers.
- `app/` contains the playable interface and search visualizer.
- `tests/` contains the solver test suite.

## Play

Run from the repository root:

```powershell
python -m app.play
```

The search visualizer and iterative-deepening solver are unfinished.
